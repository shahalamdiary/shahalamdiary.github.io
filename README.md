# My Diary Website (GitHub Pages)

This folder contains a static homepage and privacy policy for My Diary.

## Files
- `index.html` — homepage
- `privacy.html` — privacy policy

## Publish with GitHub Pages
1. Upload these two HTML files to the root of a dedicated public GitHub repository.
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch `main` (or the repository's default branch) and folder `/(root)`, then Save.
5. Wait for the Pages deployment to finish. The website URL will be shown in Settings → Pages.

## Important before OAuth verification
- Confirm the privacy policy matches the final released app and actual data handling.
- Replace the contact email if the developer contact address changes.
- GitHub Pages subdomains are not custom domains owned by the app developer; Google's OAuth domain/brand verification requirements may still require a separately owned and verified domain.
- Never upload Firebase service-account keys, signing keys, passwords, user diary data, or other secrets to a public repository.
